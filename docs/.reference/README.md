# `docs/.reference/` — archived service docs (first pass)

These docs accompanied the original Phase 2 infrastructure, written by Claude. The corresponding modules (now in `infra/.reference/modules/`) were torn down and will be rebuilt with the user driving decisions.

## What's here

- `services/azure-container-registry.md`
- `services/azure-network.md`
- `services/azure-postgres-flexible.md`

## How to use it

When you're drafting a new service doc, compare against the archived version *after* you've made your own decisions. Treat it as a sanity check, not a template — copying it defeats the point of the redo.

## When this archive can be deleted

Once the redone service docs are written and committed, this archive is just historical. Git history retains it regardless.
